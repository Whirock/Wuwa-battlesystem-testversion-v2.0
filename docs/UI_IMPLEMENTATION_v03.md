## 已实现的界面与交互

- 战场默认收起菜单。当前友方向左前移，三角箭头随角色局部头顶锚点定位；原图方向与不对称饰品不翻转。
- 点击当前角色或按 Enter 打开操作菜单。背景和其他单位景深模糊、压暗，当前角色最后清晰绘制。
- 根菜单为战斗、技能、延奏、交涉、逃跑。防御、道具与结束行动位于战斗子菜单；无撬防和鼓舞入口。
- 选择动作后收起菜单与详情，使用目标条、场上点击或方向键选目标。Esc 回到原动作菜单，空白点击关闭选择，不消耗资源。
- 确认后同步锁定输入并仅调用引擎一次，重复 Enter、连续点击和演出中输入不重复支付。单次动作结束关闭界面；同一角色窗口有剩余 AP 时可以再次打开。
- 6 格普通 AP 与 2 格青色临时 AP 分开显示。动作详情包含 AP、角色资源、共振伤害与实际目标伤害预测。
- 普通敌人不显示共振条或常规动作详情；公开危险动作显示预警与对策，暴露部件有独立生命显示。
- 状态名下划线并可键盘聚焦。提示使用引擎实际规则及当前预测值，包含属性、护盾剩余量、裁线攻击变化和挑衅风险。
- 敌人围绕友方阵形中线排列，精英/头目前置；单精英与两普通敌人采用中心前排、上下对称后排。
- 详情面板按当前角色实际绘制包围框避让，窄舞台中保留 12px 水平间距。
- 保留头像行动顺序、相对路径离线加载、素材/背景/音频导入、原尺寸审图、校准、项目保存和导出。旧战局与新版规则不混用，素材配置迁移保留。

## 新素材与云隙索

漂泊者为一个战斗实体，四种属性机制与四种性别服装外观分别选择。优先使用属性动作映射，语义复用及原因见专项清单的 `aliasReasons`。所有头像来自运行本体的技术裁切，不包含研究参考截图或官方模型原样素材。

友方按站立身体参考高缩放，不用当前蹲坐、倒地、腾空或长剑外框强行等高。头顶箭头使用 `anchors.head`；已有头像区域和 Alpha 上缘仅作为明确的几何回退。源 PNG 不改写，工作台可调头顶与接地点。

导电技能只在已结算事件的短演出区间（12%–82%）绘制独立三色硬边像素折线。起点读取当前本体的 `rightPalm/cast` 锚点，并随缩放、前移和窗口尺寸换算；终点取该次行动事件的实际目标。效果不改变伤害、段数、目标或 AP。

取消选择不创建云隙索，重开/读取/导入清空，演出结束自动移除。减少动作模式使用静态短显示，不增加闪烁。其它解放的完整独立视觉效果不因动作本体齐备而被标为完成。

## 焦点时序修订

已隔离两处延迟首焦点回调：打开菜单后，用户若在下一绘制帧前移到其他按钮，旧回调会把焦点拉回首项；选择动作后，用户若立即聚焦取消，旧回调会把焦点拉回目标。修订将这两次首焦点设置改为DOM渲染后同步执行，防止覆盖后续用户操作。旧版的两类抢焦反例已复现，修订后四项新增回归通过；既有122项复跑通过。

此修订不改菜单布局、图像或战斗规则。快速自动化鼠标连点中出现的坐标/滚动异常仍需单独按实机证据判断，不能把焦点修订当作其根因已确定或已修复。
