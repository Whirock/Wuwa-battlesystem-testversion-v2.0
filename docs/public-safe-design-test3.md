# v3.0.0-test.3 实施与验收计划

这是可玩程序的代码级实验说明；所有战斗数值均是本项目回合制候选，不宣称原作复现或已平衡。本次以个人 AP 与数值共振为主，配合敌人分型反制。实现完成后分别记录程序测试、独立 QA 与真实浏览器验证，不用模拟 DOM 冒充实机。

## 本次实现

1. **个人行动窗口**：每人入场普通 AP=4；第二轮起 +4，普通池上限6并结转。每轮一个速度窗口，窗口内重复执行可负担技能，不设三动作上限。0AP结束不获资源；1AP防御结束窗口；状态按明确轮次/窗口计时。
2. **延奏**：个人协奏入场20、上限100、每轮实际获得最多40（候选）。只在本人窗口至少完成一个付费动作后，以100协奏选队友并关窗。接收者得专属增益及独立临时2AP，临时优先扣除；下一本人窗口结束清除，不插队、不叠加、不刷新期限、不自选。
3. **六属性**：冷凝/热熔/导电/气动/衍射/湮灭。移除武器弱点、通用元素弱点、撬防、鼓舞；DEF是通用减伤。属性倍率与独立免疫标志分开。
4. **共振**：小怪无条；标准精英1800HP/96共振，Boss4800HP/240共振起测。每招单独伤害系数和削条，动画段数不重复领额度。琳奈保留流彩刻度，普攻产生30，60流彩可选高削条或高伤害。击破取消已准备危险技，并按敌人是否已动跳过恰好一个窗口；不加1.5易伤、不加默认恢复锁。自动联合以主属性200/目标DEF160/20级/中性抗性时总伤80为参考，只结算一次；各参与者实际属性、免疫与DEF独立结算，不返AP/资源/协奏/削条。
5. **C型机制选择**：
   - 坚岩斗士：架岩反击。可1AP佯攻卸架、护盾/减伤承受一次反击、或投资共振击破。单体蓄力明确锁定后不能再被挑衅改人。
   - 车刃镰：旋刃蓄力暴露160HP部件。2AP的部件攻击不打主体、不削共振、不回资源；拆部件使本次群攻×0.45，或者花削条取消，或者防御/场域接招并处理裂伤。
   - 无冠者：阶段阈值立即预警，次轮阶段转换替换原窗口；升空暴露220HP锚点。拆除取消此次坠击，也可投资共振或全队预防性防守。无第二免费Boss窗口。
   - 惊蛰猎手：无共振的危险点杀小怪。可集中伤害击杀，或被锁定者防御/队伍保护；不拿共振题套给所有敌人。
   - 属性棱镜：按已核实五种加入冷凝、热熔、气动、衍射、湮灭；同属性独立免疫，其他属性抗性按已核实数据映射。没有证据的导电棱镜和反射/回血不加入。
6. **漂泊者**：一个战斗角色、四属性模式、男女默认/校服四外观。技能保留属性不同的资源与作用。首批实装动作逐项绑定新图，完整动作制作范围和未完成项单列，不拿待机图冒充全动作。
7. **预警**：普通下一招和随机目标不提前泄露；已准备危险技、明确锁定、部件耐久和反制方式可见。
8. **兼容**：保留旧程序与旧Release；旧战局拒绝混载，素材配置可迁移。新快照严格校验AP/资源/状态/队列，拒绝定义与数值篡改。

## 验收清单

- [ ] 开局4不是8；轮初+4至6；保存普通AP；临时优先支付；AP耗尽且无合法满协奏延奏自动关窗
- [ ] 6+2可做四个2AP动作；同名伤害技按AP/资源重复
- [ ] 延奏晚收不插队；不叠加；temp已用完也不能同窗再收；窗口末过期
- [ ] 付费动作后刚满100可立刻延奏；来源每轮最多一次；个人协奏收益≤40
- [ ] 无效/重复支援不刷通用资源；拒绝命令不改变任何状态
- [ ] 低阶无共振；击破未动跳本轮/已动跳下轮；无易伤/恢复硬锁
- [ ] 主体/部件各自扣血；联合作用只一次且按参考预算/实际属性抗性DEF结算；衍生不递归
- [ ] 锁定不被挑衅重写；普通意图隐藏；不同精英的付费替代路线都可执行
- [ ] 六属性免疫/抗性与DEF独立；四漂泊者模式/五棱镜有效
- [ ] 长战/全削条阵容检查持续压制与有效威胁；报告首次破、敌有效攻击、治疗AP和击杀轮
- [ ] 逐步保存恢复可继续，旧版快照明确拒绝，恶意/畸形存档拒绝
- [ ] 独立QA与真实浏览器可玩性、重复点击、重开、读档、窗口输入和素材绑定检查
- [ ] 原84友方+5敌PNG哈希保持；新动作/棱镜清单与缺图检查
- [ ] 发布包含离线必需文件，排除私人设计主稿、模型、制作源/私有研究

具体通过/失败/未测状态在最终测试记录里更新。本计划不是完成报告。

## 验证后修正

- 独立QA在致死架岩反击后发现后续标记/自增益仍结算，导致合法存档不可恢复。引擎已统一终止阵亡来源的剩余AOE、治疗、标记与形态效果；四种漂泊者与群攻中断回归已加入。
- 标准Boss原本三种四人阵容只普攻也能6轮获胜，不满足机制压力目标。保持4800HP/240共振，调整有准备预告的坠击至3.6系数、阶段群攻至1.65系数；新增阶段阈值即时预警。用多阵容、多种子比较普攻、拆部件、防御、治疗和削条路线，不增加恢复免疫或额外窗口。
- 漂泊者单独125能量池为候选资源，未加入原五位角色；不声称原作四属性均为125。

- 追加对称中断规则：敌方群攻同样在来源被反击击倒后停止未结算目标/异常。止戈反击减伤使用专用0.6下限，不被普通0.65下限悄悄覆盖；预览和实扣同步。

- 挑衅保留旧版有成本效果：尚未锁定的下一次单体攻击转向施放者，同时该次伤害+15%；范围/已锁定不改写。当前核心未删除这项成本，UI与规则说明必须显示。
