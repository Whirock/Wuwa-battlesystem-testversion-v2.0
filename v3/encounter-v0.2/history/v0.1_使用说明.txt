鸣潮回合制 3.0 · 遭遇演算
离线可运行测试候选 / 2026-10-09

验收范围：已过引擎与DOM事件集成测试；未完成真实浏览器视觉、音频及Windows双击验收。
图像已导入。默认使用中性舞台、无背景音画素材且静音。
最少启动步骤：完整解压 → 双击 index.html（不要从ZIP内直接打开）。

一、运行
1. 完整解压 ZIP 到任意文件夹，不要只从压缩包内打开 HTML。
2. Windows 双击“启动遭遇演算.cmd”，或用 Edge / Chrome / Firefox 打开 index.html。
3. 无需安装依赖、启动服务器或联网。assets 文件夹和全部 JS/CSS 必须与 index.html 保持原相对路径。
4. 第一次打开默认进入 4 人普通遭遇。点击“编队 / 遭遇”更换 1–4 人队伍、等级、战斗模式和普通/精英/头目/自定义敌组。
5. 私有网页版本与离线版同一套程序，存储互相独立。自定义素材通过“导出项目 / 导入项目”迁移。

二、手动战斗
• 指令 → 合法目标 → 确认。选择、取消、关闭弹窗都不消耗行动。
• 资源、形态或目标条件不足时按钮列出原因；协商在这批敌人上明确禁用。
• 敌人自动按技能模式行动，显示下一次技能预兆。行动队列按固定速度排序。
• 等待保留本轮普通行动，排到队尾，每人每轮一次。
• 个人协奏到100后展开“个人协奏”，选择接收者并释放，不增加普通行动。
• 自动演算和“执行一步”是额外测试工具，手动操作不依赖它们。
• 保存战局后刷新会恢复。同一浏览器同一来源保存；浏览器无痕/禁用存储时请导出项目。
• 胜利、全员失能、全员撤离均会结束。长时间双方无法击败对方可自行重开，不会伪造超时战败。
• Tab 导航、Enter 激活焦点按钮、Esc取消当前选择或关闭窗口。减少动态可在素材工作台中启用。

三、素材工作台
“角色 / 动作”：89个素材槽，包括84个友方动作与5个敌主体。
• 每个动作槽可导入 PNG/WebP/JPG/GIF，最大20MiB。SVG与远程URL不接受。
• 每动作可校准显示倍率、X/Y偏移、离地高度、身体参考高度、屏幕外描边、接地锚点和武器锚点。
• 接地锚点使用原图归一化坐标，允许落在画布外，保留悬浮角色的虚拟接地线。
• 锚点目前为视觉候选，用户可用场景重新校准；不冒充逐图已在引擎内验收。
• “应用到本形态”会复制当前校准，特殊动作仍应分别检查接地点。
• 非机制外观可切换；爱弥斯人形/机兵和达妮娅布景/幻灭由战斗机制控制。

“背景”：导入、铺满/完整显示、透明度与恢复中性舞台。
“音乐 / 音效”：BGM、选中、确认、攻击、受击、破盾、协奏、变身、胜利、失败各自独立导入和试听；总音量、BGM、音效音量分别调整。
• 音频支持常见WAV/MP3/OGG/M4A/WebM文件头，最大30MiB，具体编码仍取决于浏览器。
• 缺省静音，无程序生成测试音。浏览器可能要求先点击声音按钮或试听解锁。
• 不包含八方旅人的背景、音乐、音效或截图。

“项目 / 缓存”：
• 导出JSON嵌入所有用户自定义图片/音频、校准、外观、设置和可选当前战局。
• 默认89张随包PNG不重复嵌入，需要保留本程序对应assets目录。导出的JSON不是独立可执行程序。
• 刷新保存使用IndexedDB。私有窗口、浏览器清理或移动离线文件的来源可能导致缓存不可用；以导出文件为可携备份。
• 导入会先验证schema、数值范围、图片/音频文件头和战局状态，不执行脚本；失败保留原项目。
• 用户导入的文件仅存当前浏览器，不上传到网站服务器、第三方或图库。
• 清理缓存不删除电脑原图/原音频。

四、表现和比例
• 敌方在左朝右，友方在右朝左/左前方。禁止负缩放和镜像，保留不对称设计。
• 指令与形态动作按assets.js映射。长动作支持顺序卡片切帧；变身采用对应转换图、闪烁与前推，不转出镜像背面。
• 受击白闪/轻震、弱点与削盾数字、独立破盾提示；敌KO后短退场淡出并立即不再可选；友方倒下图留场。
• 84动作不是84个独立战斗技能；等待/挑衅/撤离等复用待机，撬防复用武器攻击，受击复用当前动作白闪。映射说明见 ASSET_NOTES.txt。
• 像素图使用最近邻，不模糊原图。屏幕空间描边在缩放之后补外轮廓，不能恢复内部像素；1px源线缩小仍可能丢失，需结合实际分辨率校准。
• 全敌共用“友方显示身体高 / 359”的基准，不按外框等高。无冠者身体1257/359≈3.50139倍，翼/武器额外延伸。
• 当前美术为已交付候选，不代表用户已逐张最终通过。达妮娅 DB03 当前源图含中间Alpha值，原样保留并明确标记。

五、机制基准
参数：v0.1r2候选；不是已确认正式平衡。
• 无BP，固定速度，每人每轮一次普通行动；技能动画段数不追加结算。
• 属性或武器任一匹配即弱点命中，削盾不相加；每行动每目标最多3点，撬防恒1点。
• 新破盾的本次攻击不享受1.5倍破盾增伤；同次全部伤害包使用行动开始快照。
• 破盾到下一轮末，第三轮开始自然恢复；精英/头目恢复后首个普通行动前最低1盾。
• 资源和个人协奏每遭遇清零；治疗、护盾、震谐、聚爆、裁线、蓄势/瞄准/岩架、延奏通道按候选规则运行。
• 头目阶段震荡替换下一次普通行动，不插入额外行动。
• 死亡清理其所属标记。该校验修正与原Python一个统计格削韧数相差1，胜负/回合/生命一致。
