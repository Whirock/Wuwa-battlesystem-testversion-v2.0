# 鸣潮回合制 3.0 · 遭遇演算 v0.2

独立、可离线运行的浏览器测试候选。包含 1–4 人编队、四类遭遇、三档难度、89 张动作/敌人图片，以及本地素材工作台。

本目录与仓库根目录的旧 Python A/B/C 测试台并存。3.0 是规则系列，v0.2 是这一遭遇测试程序的迭代版本；不是旧 `develop/v0.2.0` 分支或纯数据包升级，不能替换旧运行时或混用存档。

## 启动

1. 下载仓库 ZIP 并完整解压，或克隆仓库。
2. 打开 `v3/encounter-v0.2/index.html`。Windows 也可双击本目录的 `启动遭遇演算.cmd`。
3. 保持 `assets/` 与全部 JS/CSS 文件的相对结构。运行游戏无需安装 Node.js、Python、npm 依赖或登录。

这是一套离线启动入口；Windows 双击、真实浏览器画面和音频播放仍待实机验证。若浏览器禁用本地持久存储，请使用“导出项目 JSON”备份自己的素材与战局。不要在 ZIP 内直接打开单个 HTML。

## 可复现测试

测试需要 Node.js 20+（本次实际使用 24.19.0）；校验工具需要 Python 3.10+。游戏本身不需要这些依赖。

在本目录运行：

```sh
node tests/engine.test.cjs
node tests/independent/v02/engine_v02_audit.cjs
node tests/independent/v02/public_asset_audit.cjs
node tests/independent/v02/metadata_queue_audit.cjs
node tests/independent/v02/bounded_progress_audit.cjs
```

DOM 测试另需安装锁定的测试依赖：

```sh
cd tests/independent/v02
npm ci
node dom_v02_audit.cjs
```

测试脚本会更新本目录下的测试结果，并生成一个 30 MiB 超限图片占位 fixture；占位文件不随仓库分发。重新运行会改变时间戳及结果文件哈希。若要校验收到的原始公开快照，先在本目录运行 `python tools/verify_publication.py`，再执行会写结果的测试。

数值对照脚本在 `tests/balance_v02/`。原图制作/原参考图对照依赖未公开的上游输入，因此只附冻结图片及已执行的素材审计结果，不冒称可从本仓库重建原始美术。

89 张图是本程序离线运行必需的冻结工作图副本，不包含完整 master 或 3× 美术档案。每张图的本地相对路径、SHA-256 见 [运行素材清单](RUNTIME_ASSETS.json)。程序不依赖 character 仓库的下载或同步状态。
