# 鸣潮战斗测试台 v0.3.1 实验版

这是本地浏览器战斗测试程序，可体验第一批 A、B、C 三种卡牌方案，选择 1–3 个角色模板、成长阶段与牌组，进行实战遭遇或原规则检查。

**本版本仍未通过正式平衡与趣味性验收，正式合格方案数量为 0。** 它不是官方客户端，不包含完整酒馆流程或 MVU 集成；第二批 D、E、F 尚未实现。

## v0.3.0 实战功能

- 两种普通敌人：突击体、散射体；一种精英：护壁体；一种头目：试验核心
- 一名自主友军：守护者，拥有独立生命、行动点、专注、护盾和冷却；只能使用已登记的攻击与护盾能力，没有治疗能力，也没有玩家指挥按钮
- 共六个实战遭遇：普通、精英、头目各有单独作战和带友军对照两种配置
- 玩家依然只有一个身体。装备 1–3 个角色模板不会增加玩家身体数量，也不会多出生命或共享能量
- 普通友军倒下不会直接判整场失败；玩家死亡判负。首批没有护送场景，不能把预留的特殊失败条件当作已实现护送玩法
- 意图显示招式、目标、段数、防护结算前伤害、费用、冷却与可打断性。行动自主选择后锁定，目标死亡按已声明规则落空，不暗中换目标

这些敌人与友军都是本项目的原创测试原型，不冒充原作角色或原作数值。实战数值固定在以早期生命 100、攻击 12 为参照的试验档，尚未校准；更高成长阶段可以进行合法性测试，但不保证难度匹配。

## 启动

1. 安装 Python 3.10 或更新版本，建议 3.12；在 Windows 安装时勾选加入系统路径的选项
2. 下载本版本程序，完整解压到独立目录，保留旧版本以便回退
3. Windows 双击 start.bat；macOS 或 Linux 在目录内运行 sh start.sh
4. 若浏览器未自动打开，访问 http://127.0.0.1:8765

也可运行 python app.py；部分系统使用 python3。端口被占用时运行 python app.py --port 8766，并访问相应端口。不要直接双击 web/index.html。关闭服务可在命令窗口按 Ctrl+C。

启动只需要 Python 标准库，不需要安装 Node.js、额外依赖包或登录。**Windows 实机启动、真实浏览器的布局与下载行为尚未完成验收**；启动说明不是平台实测承诺。

## 第一轮试玩

- 在准备页比较 A、B、C，选择角色与成长阶段；出现必选路线时先完成选择
- “测试类型”选择“实战遭遇”体验新行动者，或“规则检查”使用原 T 系列与空间夹具
- 阅读遭遇的胜负条件、敌人和友军说明，再检查牌组开战
- 战斗中的目标、分支和合法动作由真实引擎给出。友军在玩家结束回合后、敌方之前自主行动
- “保存对局”用于本地恢复；“导出试玩记录”用于反馈。保存文件含隐藏牌序与随机状态，不宜当作公开战报分享

个人存档和下载的角色数据包位于 user_data 目录，不随程序发布。请自行备份。服务只监听本机回环地址，不应直接暴露到公网。

## 版本与存档

原 T1–T6 继续使用冻结的旧规则引擎；新实战使用独立的新引擎。旧规则存档和实战存档分别识别，不会静默迁移或换用另一套语义。

恢复要求对应引擎、角色数据包与实战内容的校验值一致。不保证任意跨程序版本兼容；若提示不兼容，请用创建存档时的程序和内容版本打开。仅支持已提交的玩家行动边界或终局存档，不支持自主行动中途保存。

应用内“检查更新”只处理兼容的角色纯数据包，不更新 Python 引擎、网页界面或本次实战原型目录。程序升级需另行下载新版本到独立目录。新旧版本的存档和程序请分别保留，历史版本不会因本次升级被覆盖。
