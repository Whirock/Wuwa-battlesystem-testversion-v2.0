最新测试版本：**v3.0.0-test.4 / 参数 0.4.0-candidate**。独立、可离线运行的浏览器战斗程序。五名角色与漂泊者四属性共9种配置、61张主动卡，按各自职责自由混搭。

下载与更新说明：[v3.0.0-test.4 Release](https://github.com/Whirock/Wuwa-battlesystem-testversion/releases/tag/v3.0.0-test.4)。选择随附完整 ZIP；SHA256 随附件提供。旧版本保留在[历史 Releases](https://github.com/Whirock/Wuwa-battlesystem-testversion/releases)。

## 启动与升级

1. 完整下载 ZIP，解压到独立目录，不要在压缩包里直接打开单个 HTML。
2. 打开根目录 **index.html**；Windows 也可使用 **启动遭遇演算.cmd**。
3. 保留全部 JS、CSS 和 assets 相对路径。游玩无需 Python、Node.js、安装依赖或联网登录。

本地素材、音频、背景、锚点校准与项目导出继续保留。新版使用独立存储，不改写旧 test.3 战局；导入旧项目只接收受支持的素材与设置，旧 AP 战局不转换为新规则存档。升级前建议导出旧项目。

## 主要规则

- 每名角色每轮一次正常行动。普攻、技能、R、道具、防御、交涉、逃跑都占行动；等待只能在同轮延后一次。
- 开场 HP/SP 满、BP1、个人共鸣能量0。BP上限5，每次可花0–3；本轮花过BP，下轮不自然补点。SP不自动恢复，CD按全局轮推进。
- 普攻0–3BP对应1–4次真实攻击；本体总倍率1/1.4/1.8/2.2。每次真实攻击按各效果条件独立触发附伤与协同，追加本体40%不缩减外部效果；协同不再触发协同。
- 技能按卡面各自的伤害、治疗、保护与Q四档预算执行。通常Q曲线为1/1.35/1.6/1.8，真实多段分配该根预算，不把总Q复制到每一击。
- 每根动作只分配一次基础能量B：本人B×ER，其他存活队友各B×0.5×接收者ER。产能者满能或锁能不影响向外共享，分享不会再分享。
- 爱弥斯、达妮娅的R1扣满能后保留R2资格并锁本人所有入能；资格不会因临时增益到期或倒下而丢失。R2只需3BP和一次正常行动，无再次满能门槛，释放完解锁。其他角色是单R。
- 只有精英及以上有共振：精英72、无冠者112、无妄者156。击破归真正完成最后Q的来源，打断允许被击破中断的动作并替换一次敌方主行动；不默认全队联合。
- HP、SP、ATK、DEF、SPD、CR、CDMG、ER自动成长至90级。五类武器仅为招式/装备分类，伤害仍是六元素与通用DEF，无武器或元素弱点盾。

## 角色与构筑

- 爱弥斯：人形削Q与机兵生命伤害取舍，双R爆发与本人击破兑现
- 琳奈：取样/巡游与单载体逐攻击追色，外部多段可提高协同收益
- 莫宁：地面/空中观测、提前选人保护、治疗场与每战一次有界
- 达妮娅：归群组织多目标、异常铺设、蓝态双R与轮末场
- 千咲：剪刀进攻治疗、电锯输出与虚湮/异常扩容
- 漂泊者：衍射光噪与留响、湮灭暗涌、气动群疗及异常转风蚀、导电条件SP接力或临界四属性攻击

性别与服装只改变外观。一队最多一个漂泊者，属性在战前选择。任意合格队友都能参与相应事件联动，没有指定姓名或固定主题队钥匙。完整费用、分支、条件、持续与BP档位可在技能详情查看。

## 遭遇与界面

普通/人形精英/异形精英、两组五属性棱镜测试、无冠者与无妄者。普通敌方下一招保持隐藏，危险蓄力公开；高压Boss蓄力霸体，只有规定机制与击破能打断。无妄者投射物是独立可选目标，可被普攻或合法群攻击中；耐久耗尽反弹54.6Q，本体Q严格低于78中断特殊蓄能，恰好78不算。

角色旁菜单有战斗、技能、道具、防御、交涉、逃跑六入口。选择BP后预览实际费用与目标；同一个R入口随阶段变化。友方增益显示在右侧角色栏，敌方减益在脚下；图标不叠剩余数字，悬停或键盘焦点可查看详情，剩最后一回合以慢闪提醒。

## 素材与已知边界

- 原158张运行PNG保持字节不变，新增无妄者首版主战待机图1张；投射物仍是明确标注的几何机制示意。无妄者只有1张待机动作复用，用户美术终审与最终实机校准仍待确认；两者均可在素材工作台替换。
- 新技能复用现有动作图和明确动作映射，不代表61张卡各新增了一套完整动画。形态、服装、临时增益分别处理。
- 参数为本项目回合改编测试候选，不是官方游戏数值。20级队伍挑战40级无妄者属于越级压力测试。
- 无妄者同级仍很难：一条40级标准合法路线36轮胜利，仅莫宁90HP存活；没有为通关改Boss数值。此证明存在路线，不代表平衡成熟。可用 `node tests/v04/independent_victory_replay.cjs` 重播。
- 自动策略胜率不是玩家胜率或最优打法证明；有界观察窗口内未结束记为未决。
- Windows双击、音频实际播放、真人乐趣与最终平衡需要各自验收。
- 本包是独立战斗原型，未接入完整SillyTavern叙事桥、正式背包经济、奖励结算、装备养成或地图探索。
