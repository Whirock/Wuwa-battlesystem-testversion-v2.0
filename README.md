# 鸣潮回合制 3.0 · AP 遭遇演算

当前测试版本：**v3.0.0-test.3 / 参数 0.3.0-candidate**。这是独立、可离线运行的浏览器战斗测试程序。新版本以个人 AP、数值共振和分型敌人反制为核心；四人编队，保留既有角色资源与素材工作台。

**这是E+C底层测试版，不代表完整主题队方案、最终平衡或美术验收。** [下载当前 v3.0.0-test.3](https://github.com/Whirock/Wuwa-battlesystem-testversion/releases/tag/v3.0.0-test.3)。旧版本在 [历史 Releases](https://github.com/Whirock/Wuwa-battlesystem-testversion/releases) 保留，不覆盖、不删除。

## 启动

1. 完整下载并解压独立程序 ZIP，或克隆仓库。不要在 ZIP 内打开单个 HTML。
2. 打开根目录 **index.html**。Windows 可用 **启动遭遇演算.cmd**。
3. 保持 assets/、JS、CSS 与 HTML 相对路径不变。游戏运行不需要 Python、Node.js、安装依赖或联网登录。

本地数据属于当前浏览器。升级前请导出素材项目，解压新版到独立目录；新路径不保证自动继承旧缓存。旧战局不能混用本次 AP 参数，素材与外观配置迁移后需重新开场。

## 如何玩

- 点击当前行动角色打开指令。选择技能与目标，确认前可查看 AP、个人资源、伤害属性、实际预测和禁用原因。
- 每人开场普通 AP=4，下一轮开始 +4 至上限6，未用普通 AP结转。同一个窗口可重复使用负担得起的技能，**没有统一三动作上限**。
- “结束并保存AP”免费关窗；防御花1AP并关窗。AP用完且无可用延奏时自动关窗；刚充满100协奏时可先选择延奏。
- 延奏只在本人完成至少一个付费动作后发动。消耗100个人协奏并结束本人窗口，接收队友获得专属增益和独立临时2AP。临时点优先用，到接收者下一本人窗口末过期，不插队、不叠加、不自选。
- 小怪没有共振条。精英/头目共振被清空后，取消已准备强攻，跳过恰好一个敌方窗口并联合攻击；取消旧1.5倍易伤和默认恢复硬保护。
- 通常敌意图隐藏。看到危险锁定或部件时，选择付 AP/资源处理、集中生命伤害点杀，或提前防御/保护。挑衅不能改写已经锁定的目标；被挑衅的下一次单体攻击伤害另+15%。

## 本次内容

- 普通、精英人形、精英非人形、头目，以及两组棱镜测试遭遇；三档难度；可自选1–4友方/敌方
- 原五位角色，加一个可切衍射/湮灭/气动/导电模式的漂泊者；男女默认/校服是四种外观，不是四个可重复编队角色
- 冷凝、热熔、导电、气动、衍射、湮灭六种伤害属性；DEF为通用减伤，移除武器弱点、通用撬防与鼓舞
- 琳奈以同一份60流彩在“高削共振”和“高生命伤害”间选择；其余角色不共享通用削条模板
- 坚岩斗士反击可付1AP卸架、保护硬接或共振破除；车刃镰暴露旋刃，拆除后削弱群攻；无冠者升空锚点拆除可取消坠击
- 五种属性棱镜：冷凝/热熔/气动/衍射/湮灭。同属性由独立免疫标志挡伤，**不回血、不反射**。本次是普通攻击简化版，未复刻原作各类支援关系；未加入无可靠资料的导电棱镜
- 原84张友方动作和5张敌人图片保留，另有五种棱镜及64张漂泊者独立动作（四套外观各16张），共158张运行PNG；共用姿势按明确映射复用，不重复计作新图
- 素材、背景和音频的本地导入、校准、保存/导出；通常操作不上传本地文件

详细实现与验收计划：[public-safe-design-test3](docs/public-safe-design-test3.md)。具体技能与费用：[参数](parameters.json)、[当前规则](当前执行规则与变更表.txt)。

## 数值与验证边界

标准精英1800HP/96共振、头目4800HP/240共振是**起测值**。削共振与生命伤害独立，原作实时秒数不直接当回合数。本版联合以200主属性、目标160DEF、20级和中性抗性时总伤80为参考；每名参与者实际按自己的属性、敌人免疫/抗性及DEF结算，不穿防固定扣80。

当前自测：54/54引擎规则检查通过；556场实际引擎矩阵完成，426胜/121败/9未决、3,754次保存恢复一致。另2700场Boss对照中，标准纯普攻88/300胜、付费拆锚300/300胜、主动防御297/300胜；轻松纯普攻300/300。独立最终矩阵1080场、48,314次逐步恢复无错误。定向QA及真实浏览器检查的最终计数与哈希见[测试报告](测试报告.txt)及 tests/v03/。旧 tests/independent/v02 与 tests/balance_v02 是历史证据，不算新版通过。

- 合成规则场景用于检查时序/边界，不称为真实平衡样本
- 策略矩阵运行的是本包真实引擎，但策略是启发式，不代表最优胜率
- 观察窗口结束仍未决的战斗保留未决，不强行判负
- 浏览器像素布局、音频、Windows双击、真人决策乐趣分别验收，不能由Node/jsdom通过代替
- 漂泊者独有的125上限“共鸣能量”是本项目新增候选池，未给原五角色追加统一解放能量，也不声称原作四属性统一125。
- 漂泊者目前是付费窗口改编：未实现完整空地分支、导电原作多属性七段。美术进度由当前素材清单列明

### 开发者复跑

仅测试需要 Node.js 20+ 与 Python 3.10+。先对发行原始副本校验，再在工作副本复跑会更新报告的测试：

```sh
python tools/verify_publication.py
node tests/engine.test.cjs
node tests/v03/benchmark_ap.cjs
node tests/v03/boss_strategy_acceptance.cjs
```

独立QA与真实浏览器脚本由各自报告给出。tools/prepare_publication_v03.py 仅供发行维护，在全部代码/素材/文档定稿后重新生成清单，不是用来跳过失败校验。

## 目录与发布范围

- index.html、JS/CSS、assets/：离线程序与必要运行图片
- parameters.json：候选参数；parameters.js为同内容的离线脚本包
- VERSION.json、CHANGELOG.md、使用说明.txt：当前版本与操作说明
