# v0.2.0 · Usability experimental prerelease

Application usability iteration; A/B/C combat rules, runtime and frozen data packages are unchanged.

- ABC side-by-side structure, benefits, tradeoffs and honest unqualified status
- Direct 1–3 role selection with separate fresh/early/mid/late stage selection
- Existing profiles resolved independently of click order
- Role introductions follow selected candidate, stage, actual private resource caps and owned cards
- Single-branch player descriptions with full immediate costs, conditions, effects and destination; linked rules folded separately, raw rules reserved for debugging
- Hand descriptions use the actual currently mapped ability; old battles keep their pinned definitions
- Separate drafts by data version/candidate/stage/roles; compatible selections preserved, invalid removals explained
- Application version is separate from combat data version

No NPC implementation is included in this iteration. Ordinary/elite/boss/NPC expansion requires a later engine iteration.

Install this application upgrade by downloading the v0.2.0 GitHub Release into a separate directory. The in-app data updater does not update Python, JavaScript or the GUI. Keep the previous release for rollback.

This is not a balance qualification, human-readability acceptance or real-browser acceptance claim. Formal qualified candidates remain 0. Runtime and frozen A/B/C data are unchanged.
