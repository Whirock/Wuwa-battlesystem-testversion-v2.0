# 遭遇演算 v0.2.0 战斗设计与数值验证
日期：2026-10-09 UTC。参数版本：0.2.0-candidate。

## 结论与边界
本次直接修改交付程序的 JavaScript 引擎与参数。旧版“特殊技能存在，但来不及完整出手”“协奏自动消耗导致满条不可见”均取得实际日志证据；新版本已落地三难度、手动协奏保留、角色接力和可反制的敌人轮转。
规则单测63/63通过；144场同级、满血、零资源、公开行动API的固定策略矩阵完成。新增自然蓄力分支实验验证防御、削盾打断、治疗的实际取舍。DOM、浏览器画面、音频与真人手感由主程序/独立QA单独报告，本报告不将脚本等同试玩。
标准精英并非所有编队都应减员。治疗后剩血高不能单独证明没有压力；因此同时记录过程中最低生命、治疗行动、技能出现次数及蓄力兑现。挑战头目对固定输出策略很严苛，部分响应预警的编队可胜，但没有“所有编队必胜”保证。

## 用户要求 → 诊断证据 → 改动
1. 难度低、精英/Boss似乎只会攻击。旧引擎已有架岩、蓄力、冲压、回旋、坠空和阶段技；不是缺少技能表。旧4人混合队打斗士5轮，只发生岩拳1/架岩1；车刃4轮，回旋0；Boss7轮，槊1/横扫1/蓄力1，坠空0，总剩余生命99.49%。盾偏少、破防跨当前及下一轮、长轮转被压制，使特殊技能很少兑现。新参数增厚精英/Boss韧性并提前关键轮转，而非另加免费行动。
2. Boss协奏打不满。旧JS实际在第5轮已有个人100协奏；默认4人Boss战自动发出4次协奏。app的单步与自动都走autoAction，而旧autoAction默默清条。普通与车刃战3–4轮结束则确实常未满。新默认autoAction不放协奏；普通有效普攻25、技能30、较大解放35，常在第4轮满，满条事件与提示明确。零资源开局、100上限不变。
3. 状态/技能看不见。旧UI只露名字、系数、资源，缺少效果、持续、反制、实际收益解释。本次引擎公开完整技能元数据、状态说明、蓄力/打断/满条/接力日志。UI是否充分展示另见主程序验收。
4. 阶段与蓄力的真实逻辑缺陷。旧phase替代wingpulse时也推进普通pattern_i，可能跳过原轮转；新阶段技占正常槽位但不推进普通索引，已开始的蓄力先兑现，再排阶段技。破防仅跳过该次已承诺强攻；未来轮转仍可蓄力。
5. 缺队伍差异。沿既有原作定位做回合制改编：琳奈接力供给；莫宁防御型治疗与场域；千咲切线减攻/异常增益、净化/盾；达妮娅红蓝异常与群攻；爱弥斯双资源爆发。没有把五人改成同质全队加攻。

## 三难度与数值
均保持固定速度、每轮每角色一次普通行动、无BP。难度不额外插入敌方行动，也没有不可打断蓄力、强制扣血或不可恢复的无限免控。
| 难度 | 敌HP | 敌攻击 | 精英/头目韧性 | 节奏与目标 |
|---|---:|---:|---:|---|
| 轻松 | ×0.80 | ×0.75 | 基准−2，最低1 | 精英/头目强攻后更长普通行动间隔；轮换目标 |
| 标准 | ×1.00 | ×1.00 | 基准 | 完整可见固定轮转；轮换目标 |
| 挑战 | ×1.15 | ×1.15 | 基准+1 | 车刃/Boss第一槽开始蓄力；斗士轮转少一次普通攻击；未锁定单体优先生命比例最低者 |

普通敌人的盾不受上述±值影响。锁定瞄准/蓄力和明确挑衅优先于常规目标规则。没有选择任何初始高资源或自动满血回填。
| 敌人 | 旧HP→标准HP | 旧攻击→标准攻击 | 旧盾→标准盾 |
|---|---:|---:|---:|
| 咔嚓嚓 | 640→780 | 230→265 | 2→2 |
| 惊蛰猎手 | 560→700 | 240→290 | 3→3 |
| 坚岩斗士 | 2850→4300 | 350→410 | 6→9 |
| 车刃镰 | 2500→3900 | 330→370 | 5→8 |
| 无冠者 | 7200→10400 | 440→465 | 8/10→12/14 |

表为20级基准，属性按既有线性等级公式缩放；速度不成长。Boss二阶段攻击×1.2、60%血线、自然恢复时使用更高最大韧性，未增加血量锁或强制清状态。

## 敌方招式、成本、预兆和反制
所有招式成本均为一次敌方普通行动。所谓冷却是明确固定轮转的行动间隔，不是隐藏实时秒数。破防暂停行动，不会趁跳过行动偷偷推进到强攻。
- 坚岩斗士标准：架岩 → 蓄力 → 岩躯冲压 → 岩拳。架岩同时0.8倍单体攻击，之后减伤×0.7；第一次非弱点攻击触发0.8倍反击，弱点/撬防避免，破防当次取消反击。冲压先用整次行动锁定单体，下次2.7倍兑现；可以破防打断，或防御减半，或挑衅接走但该单体伤害+15%。轻松尾部多岩拳；挑战省去岩拳。
- 车刃镰标准：挥击 → 蓄转 → 全体回旋。挥击1.25倍并施加裂伤（治疗×0.75，到下回合末，可净化）。回旋蓄一整次行动，下次全体1.8倍。全体不能用挑衅改目标，破防/防御可反制。轻松尾部多挥击；挑战首槽蓄力。
- 无冠者标准：连槊 → 升空蓄势 → 坠空裁决 → 羽锋横扫。连槊1.5倍单体；裁决蓄一整次行动后全体2.15倍；横扫全体0.95倍并施加暴露，下一次受击+15%、一次后消耗或下回合末结束。净化/防御/安排破防窗口有不同成本。展翼阶段震荡全体1.35倍，用一个正常槽位，随后继续未跳号的原轮转。轻松把横扫放在蓄力前且多一个连槊；挑战起手升空。
- 惊蛰猎手保留雷矢 → 瞄准 → 贯射2.2倍；瞄准锁定、目标离场时选合法替补、挑衅可显式改向。咔嚓嚓保留扑咬/热团。
- 蓄力开始、兑现、被破防打断、蓄力中被击倒取消均有独立日志。告知取消原因很重要：没有兑现的技能不再被含混描述为“没有技能”。

## 队伍互动、资源与状态边界
- 爱弥斯：同步200/谐振4；终结和双形态路线、返形共享生命仍保留。接收主资源供给可更早到关键门槛，不增加普通行动。
- 琳奈：留彩校准现在放置震谐标记。另一队友弱点命中消耗标记：原有0.5倍归属标记者的异常包、额外1削韧，以及命中者10主资源。一次普通行动即使多目标触发也最多供给10；撬防仍固定削1，不因标记变成2。派生异常伤害本身不回资源/协奏。
- 莫宁：DEF参与伤害和治疗；场域直接增伤15%、所受伤害×0.8，到下回合末。单体治疗为2.2×DEF+等级缩放平值100，群体1.4×DEF+平值80；占用校准和普通行动。UI有当前等级/熟练预计治疗值，裂伤和过量治疗另计。
- 达妮娅：红蓝资源软锁修复保留；3层聚爆异常包0.9→1.2，蓝形态每次施加2层；场景群攻只结算一次资源/协奏。与千咲切线和异常延奏协作，但没有递归追击。
- 千咲：切线令敌攻击×0.85并使异常包增伤25%，持续最多2次敌行动且最晚施放后第3回合末。缝合界线恢复后可净化裂伤/暴露，给最多150盾至下回合末；护盾刷新取较高值，不叠加无上限。
- 鼓舞：另一个队友下一次直接攻击+25%，与延奏普通增伤取高值。首次有效新加鼓舞得15协奏；重复未消耗的同一buff不再赚条。挑衅同样只在有效新施加时得15。群攻不会消费“下一次单体”的挑衅，最长施放后第2回合末。
- 延奏普通、解放额外两通道各保留较强值；与场域合计直接增伤封顶50%。异常延奏单独一次令牌，等其所有者后续异常包触发，切线+异常延奏总封顶50%，不被普通直击提前吃掉。
- 每人协奏100，开局0；一次有效普通行动最多35；同一人每轮最多发一次。变奏每接收者每轮最多20主资源，绝不补协奏。单人自协奏只有半额直接增伤，不能靠自协奏制造资源循环。默认单步/自动操作都保留手动条，接口显式auto_concerto:true仅为可追踪的演算选择；日志区分manual/automatic。
- 失能/撤离清自己的状态、个人资源、形态、本人拥有的震谐/挑衅标记。已经给别人的延奏/护盾，以及独立计时的切线/聚爆/场域按原期限结束，不复活施放者，也不追加行动。
- 等待每人每轮一次，原行动令牌排至本轮队尾；等待不延长上次防御。破防仍持续至r+1末，r+2自然恢复；精英/头目恢复后必须完成一个真实正常行动才解除盾底1保护，避免无限破防软锁。

## 六菜单实际功能
战斗：普通攻击、爱弥斯满谐重击、撬防、等待。技能：角色技能与个人协奏入口。防御：明确减半持续与确认。道具：每场隔离测试库存2修复剂（30%最大生命）+1净化剂（净化并恢复12%）；正常行动、无协奏、不复活、没有货币/掉落/正式背包经济。交涉：鼓舞/挑衅可用，当前敌人没有剧情协商/交易分支。逃跑：单人撤离，保留HP并清战斗资源；全员/部分撤离与胜利/失能分开计。

## 144格验证设计
接力三人、混合四人、异常四人、两人压力参考，各跑3难度×4遭遇×3策略。level=20，HP=100%，所有战斗资源=0，没有注入敌人状态/资源、回填生命或改变敌人技能。道具库存所有策略相同；主矩阵不使用道具。60回合只是观察边界，若未分胜负记inconclusive，不能判负。
协作策略调用与UI相同的公开concerto(actor,target)，验证“自然达到满条→手动API可成功→不吃普通行动”；这是脚本调用，不冒称真人按过按钮。仅不协奏对照使用相同技能/治疗选择逻辑，只不发协奏。自顾输出对照不主动survey/field/cut且不发协奏，仍可治疗，输出技能自带的偶发标记仍存在，故不将它误称为“完全无buff”。

- 标准精英接力三人：斗士9轮胜，最低64.85%，治疗后末98.40%；车刃7轮胜，最低55.76%，末67.93%，回旋兑现2次。混合四人可以更早打断斗士，仅最低85.62%；挑战斗士该队最低52.39%。这显示组队控制力和治疗覆盖有差异，不把高终场血量自动改成高不可反制伤害。
- 两人压力参考：标准斗士14轮/最低65.67%、车刃12轮/最低60.61%，Boss26轮败；挑战车刃最低34.94%，Boss20轮败。没有用两人样本当作四人标准难度。
- 相同固定策略的难度结果不保证每个指标严格单调：轮转与目标改变可恰好更好被破防，治疗时机也改变。难度不是HP百分比的简单排序，不能据这些确定性样本推断真人胜率。

### 蓄力反制分支
1. 同一个自然到达的标准Boss蓄力存档（r2、剩4盾）分支：接力削盾方案用合法技能/治疗，在兑现前破防，强攻伤害0；全员防御分支不削盾，兑现造成全队1219伤害；莫宁治疗+其他人防御分支实际治疗429，但莫宁放弃防御导致合计1482伤害。每个分支保留各自资源与敌血差异，没有免费支援。
2. 另一个同存档防御对照：未防御继续普通攻击时全队受2441伤害；全员防御为1219，近似减半，取整造成1–3点差异。
3. 挑战补充响应策略（区别于主矩阵）：先用可见固定序列判断本次能否破防；不足则防御，危急时用两瓶有限测试修复剂。混合四人20轮胜但减员2；爱/琳/莫/千19轮胜、减员1；接力三人和异常四人仍败。此补充同时改变预警响应和道具使用，不声称单独量化防御造成的胜负变化。
